# Чисто34

Демонстрационный сайт клининговой компании из Волгограда. Компания, цены, телефон и отзывы вымышлены. Сайт показывает, как может выглядеть лендинг услуг с онлайн-расчётом и заявкой.

## Что умеет

- Калькулятор уборки: тип (поддерживающая, генеральная, после ремонта), площадь, дополнительные услуги, итоговая цена и время работы бригады.
- Интерактив «сотри грязь»: чистая комната проявляется, когда провести по ней пальцем или мышью.
- Заявка с проверкой имени и телефона и страницей подтверждения. Данные никуда не отправляются, а сохраняются только в браузере посетителя.
- Светлая и тёмная тема, мобильная версия с закреплённой кнопкой заказа.
- Разделы: услуги, как работаем, прайс, отзывы, вопросы и ответы.

## Стек

Next.js (статический экспорт), TypeScript, Tailwind CSS v4, React Hook Form и Zod, шрифты Onest и Unbounded.

Демо-проект студии Akimov Web.
